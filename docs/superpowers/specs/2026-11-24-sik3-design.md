## 2. Batasan (Constraints)
- **Lingkungan Fisik:** Bengkel sekolah dengan pencahayaan bervariasi, seragam wearpack beragam antar jurusan/sekolah, dan sinyal internet sering tidak ada.
- **Perangkat:** HP Android kelas menengah (RAM 4–6 GB); foto bukti dikompresi maks 800px JPG dan dilengkapi pembersih foto draft.
- **Standar Desain (`/ui-ux-pro-max` + `/impeccable` mode *Operate* + `/design-eng`):**
  - Palet dari Logo SiK3: Primary Navy `#0D2D4D`, Safety Amber `#F59E0B` (`#D97706` pressed), Surface `#F8FAFC` / `#FFFFFF`, Scanner Dark `#0B192C`, Lolos `#15803D`, Perlu Cek `#D97706`, Kurang `#DC2626`.
  - **Zero emoji** di seluruh antarmuka dan laporan PDF — 6 item APD wajib menggunakan ikon SVG murni (`viewBox="0 0 24 24"`, stroke konsisten 2px).
  - Target sentuh ≥ `48×48dp` (spacing ≥ 8dp).
  - Tabular numbers (`FontFeature.tabularFigures()`) untuk NISN, No. Presensi, jumlah siswa, dan skor confidence.
  - Radius konsentris ($R_{inner} = R_{outer} - P$).
  - Transisi ease-out cepat 150–200ms, tanpa bounce berlebihan, hormati reduced motion.
  - Material 3 native Android components, edge-to-edge safe areas, system Back selalu bekerja.
- **Disiplin Kode (`/kcode`):** Tepat 3 tabel SQLite (`classes`, `inspection_sessions`, `scan_records`), solusi minimalis tanpa over-abstraksi, perubahan presisi, verifikasi terukur (TDD).

## 3. Arsitektur 2 Subsistem
1. **Subsistem A (Utama — 100% Offline, Flutter Android):**
   - **Mode Siswa:** Profil lokal (Nama, NISN, No. Presensi, Kelas, Jurusan) → Kartu QR Identitas kontras tinggi (`{"v":1,"nisn":"...","absen":"...","nama":"...","kelas":"...","jurusan":"...","chk":"xxxx"}`, CRC16 4-hex lowercase).
   - **Mode Guru (PIN lokal 4–6 digit, hash SHA-256):** Profil guru mapel (Nama, NIP opsional, Nama Sekolah/Jurusan, URL Verifikasi AI opsional), manajemen daftar kelas + Wali Kelas + preset 6 APD wajib, pemindaian QR siswa (`mobile_scanner`) + input manual cadangan jika siswa lupa HP, kamera 2-zona (`camera` + `tflite_flutter` modular), validasi draft SQLite (`sqflite`) dengan koreksi 1 ketuk, dan pratinjau/cetak/bagikan PDF A4 (`pdf` + `printing`).
2. **Subsistem B (Opsional — Online Assist, `api-verify-apd/`):**
   - Next.js / Vercel Route Handler `POST /api/verify-apd` (Node.js runtime) memakai Vercel AI SDK v6 (`generateText` + `Output.object()` + Zod schema + model `google/gemini-3-flash` via AI Gateway).
   - Dipanggil hanya jika guru mengisi endpoint URL di pengaturan dan menekan "Verifikasi AI Tambahan" saat online. Timeout ≤ 10 detik, gagal elegan (`VerifyFailure`) tanpa merusak draft SQLite, dan hasil AI hanya diterapkan setelah guru mengonfirmasi.

## 4. Aturan Deteksi 2-Zona & Ambang Keyakinan
- **Zona Atas (±1–1,5 m):** `helm`, `kacamata`, `masker`, `baju_praktik`, `sarung_tangan`.
- **Zona Bawah (area kaki):** `sepatu_bengkel`.
- **Modularitas Model:** `assets/models/ppe_detector.tflite` + `assets/models/ppe_labels.json`.
- **Ambang Keyakinan:** `confidenceThreshold = 0.70`.
  - Skor ≥ `0.70` → `ApdStatus.detected` (Lolos, `#15803D`).
  - Skor < `0.70` (tetapi > 0 / terdeteksi lemah) → `ApdStatus.needsReview` (Perlu Cek, `#D97706`).
  - Item diwajibkan tetapi **tidak ada di `config.supportedItems`** (belum tercakup label model PPE publik, mis. `baju_praktik`) → **WAJIB `ApdStatus.needsReview`** (Perlu Cek), BUKAN `ApdStatus.missing`.
  - Item diwajibkan, didukung model (`supportedItems.contains(item)`), dan tidak terdeteksi sama sekali → `ApdStatus.missing` (Kurang, `#DC2626`).
  - Item tidak diwajibkan → diabaikan dari hasil evaluasi.

## 5. Skema Database SQLite (Tepat 3 Tabel)
1. `classes`: `id` (PK AI), `name` (TEXT NOT NULL), `homeroom_teacher` (TEXT NOT NULL), `homeroom_nip` (TEXT), `required_apd_json` (TEXT NOT NULL).
2. `inspection_sessions`: `id` (PK AI), `class_id` (INT NOT NULL FK→classes), `subject_name` (TEXT NOT NULL), `teacher_name` (TEXT NOT NULL), `teacher_nip` (TEXT), `homeroom_teacher` (TEXT NOT NULL), `homeroom_nip` (TEXT), `school_name` (TEXT), `session_date` (TEXT NOT NULL), `required_apd_json` (TEXT NOT NULL), `status` (TEXT NOT NULL DEFAULT `'draft'`).
3. `scan_records`: `id` (PK AI), `session_id` (INT NOT NULL FK→inspection_sessions), `nisn` (TEXT NOT NULL), `attendance_no` (TEXT NOT NULL), `student_name` (TEXT NOT NULL), `apd_results_json` (TEXT NOT NULL), `upper_photo_path` (TEXT), `lower_photo_path` (TEXT), `is_manual_override` (INT NOT NULL DEFAULT 0), `is_ai_verified` (INT NOT NULL DEFAULT 0), `scanned_at` (TEXT NOT NULL), `UNIQUE(session_id, nisn)`.

## 6. Struktur Laporan PDF A4 Offline
- Multi-halaman otomatis (`pw.MultiPage`, format A4 portrait, margin rapi).
- Kop: Logo SiK3 transparan (`logo_sik3_transparent.png`), Judul *LAPORAN INSPEKSI PENGGUNAAN APD / K3 BENGKEL*, Nama Sekolah/Jurusan, Kelas, Mata Praktik, Tanggal.
- Tabel Siswa: `No`, `Absen / NISN`, `Nama Siswa`, **kolom dinamis hanya untuk APD wajib sesi** (simbol vektor centang hijau / tanda tanya amber / silang merah — nol emoji), `Status` (`Lengkap` / `Perlu Cek` / `Kurang`). Header tabel otomatis berulang di halaman lanjutan.
- Ringkasan: Total siswa diperiksa, Lengkap K3, Perlu Cek, Kurang K3.
- Blok Tanda Tangan sejajar (tidak terpotong antar halaman via `pw.Wrap`/`pw.Container` non-spanning): Kiri **Guru Mata Pelajaran** (nama terang + NIP opsional), Kanan **Wali Kelas** (nama terang + NIP opsional).
